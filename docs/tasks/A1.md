## 新模型

1. **音軌**：描述檔 `<AudioTracks default="<名字>" followGameLanguage="0|1">`，每條 `<Track name="…" embedded="1" | file="…" | trigger="…" [pauseTrigger= resumeTrigger=] [language="…"]>`。`name` 是作者自取的識別字（`[A-Za-z0-9_.-]`，1～63，不分大小寫，不得重複）。`language` 是選用的標記（自由字串，建議用引擎語言名，例如 `english`），不參與選軌——除非 `followGameLanguage="1"`。沒有 `<AudioTracks>` 的描述檔與單純的 `.webm`：照舊（內嵌聲音，一條隱含的音軌）。
2. **選軌順序**：(1) 明確指定的音軌（`SetAudioTrack(name)`，名字不存在 → 警告一次並視為未指定）；(2) 若 `followGameLanguage="1"`：`g_languageAudio`，再 `g_language`，比對各音軌的 `language` 標記（不是 `name`）；(3) `default`；(4) 第一條音軌；沒有音軌時是內嵌聲音。**預設（屬性省略）`followGameLanguage`＝0**：不讀任何遊戲語言 cvar。
3. **介面改名（不留舊名）**：`IVideoPlayer::SetAudioTrack/GetAudioTrack`（介面版本維持 5——尚未對外發佈；在標頭註解記下這次改名）；描述表 `SetAudioTrack`（參數 `Track`）與查詢 `AudioTrack`，另加查詢 `AudioTrackCount`、`AudioTrackName(Index)`（讓腳本能列出音軌）與 `AudioTrackLanguage(Index)`；舊的 `SetLanguage`／`Language` 兩項的 GUID 退役（列入表頭的退役清單），新項目用新 GUID。FlowGraph `Settings` 的埠改 `AudioTrack`、`Info` 的輸出改 `AudioTrack`；Schematyc 與 CryVS 的屬性與函式同名修改（CryVS 在這棵樹編不到：保持原始碼一致並在報告註明）。主控台 `cev_lang` → `cev_audiotrack <handle|surface> <name>`。內部 `ReloadForLanguage` 之類的名稱一併改成音軌用語。
4. **編輯器**：Info 欄的區塊改為「Audio tracks」：每列 Name、Source（Embedded／File／Trigger）、對應欄位、Language（選用）；上方「Default track」下拉與「Follow game language」核取方塊（附一句說明：勾選後依遊戲的語音語言比對各音軌的 Language 標記）。預覽：多一個「Audio track」下拉可直接切換試聽（不再跟隨遊戲語言 cvar；`followGameLanguage` 在預覽中只顯示不作用，狀態列註明）。匯入對話框／離線處理中「語言」的字樣同樣改掉（分離音軌、外部音檔的命名規則若以語言為名，改為以音軌名）。
5. **文件**：README 的描述檔說明與指令表、`docs/design/M2-audio-and-bindings.md` 與 `M4-asset-and-editor.md` 末尾各加一節「2026-11-19 修訂（A1）」說明新模型（不逐句改寫舊段落）、`docs/design/M6-ui-source.md` §4.2 的節點表（`Settings`／`Info` 的埠名）。
