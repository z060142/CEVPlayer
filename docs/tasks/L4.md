## 1. `Module/Render/FullscreenOutput.h/.cpp` 重寫

介面（取代現有的 `Draw`／`DrawTextLines`）：

```cpp
namespace CEVPlayer { namespace FullscreenOutput {
    enum class EBackend { None, XUI2DL };          // XUI2D 之後另一張單加
    struct SLayer                                   // 一個全螢幕播放器
    {
        int               textureId = 0;
        int               imageWidth = 0, imageHeight = 0;     // 畫面尺寸（不是打包貼圖的尺寸）
        EVideoFit         fit = EVideoFit::Letterbox;
        EVideoPixelLayout layout = EVideoPixelLayout::RGBA8;
        bool              hasAlpha = false;
        // 打包排列才用（值照契約快照：planeY/U/V/A、colorMatrix、colorRange、chromaSiting）
        uint32 planeY[4] = {}, planeU[4] = {}, planeV[4] = {}, planeA[4] = {};
        uint32 colorMatrix = 0, colorRange = 0, chromaSiting = 0;
    };
    struct SDebugLayer { int textureId = 0; float x = 0, y = 0, w = 0, h = 0; float color[4] = {1,1,1,1}; bool solid = false; };

    EBackend Backend();            //!< 探測一次並快取；None 時記一行錯誤（每次執行一次）
    bool     SupportsPlanar();     //!< 後端有 XUI2DL_CAP_YUV
    //! 每幀呼叫一次（UpdateAfterRender）。把圖層換算成後端的清單；與上次送出的內容逐位元組相同就不送。
    void Present(const SLayer* pLayers, size_t count, const SDebugLayer* pDebug, size_t debugCount);
    void Shutdown();               //!< 送出空清單
    void SetProbeOwnsFrame(bool owns);   //!< cev_probe_xui2dl 直接呼叫後端時為 true：Present 不送；改回 false 時下一次 Present 強制重送
} }
```

`Present` 的換算：

- 輸出大小照現行做法（`GetOverlayWidth/Height`，為 0 時退回 `GetWidth/Height`）。大小改變 → 內容自然不同 → 重送。
- 每個 `SLayer` 的目的矩形照現行的 `Fill`／等比／`Letterbox` 計算（把現有 `Draw` 的算式原樣搬過來）。`Letterbox` 的四條黑邊各一個 `XUI2DL_KIND_SOLID`（黑、不透明、`XUI2DL_BLEND_REPLACE`），寬或高 ≤ 0 的不送。
- 影片圖層：`RGBA8` → `XUI2DL_KIND_RGBA_PREMULT`；`PackedYuv420` → `XUI2DL_KIND_YUV420`；`PackedYuva420` → `XUI2DL_KIND_YUVA420`。混合一律 `XUI2DL_BLEND_SRCOVER`，`color` = (1,1,1,1)，`src` = 整張，`scissor` 無。
- 除錯圖層接在最後：`solid` → `KIND_SOLID`／`REPLACE`；否則 `KIND_RGBA_PREMULT`／`SRCOVER`。
- 總數超過 `XUI2DL_MAX_LAYERS`：從除錯圖層開始丟，再丟最上層的播放器；記一行警告（每次執行一次）。
- 沒有任何圖層：上次送出的不是空清單才送一次空清單。
- `Backend() == None`：什麼都不送。錯誤訊息固定為：`fullscreen output is unavailable: the renderer has no XUI2DL (apply EnginePatch/apply_xui2dl.py and rebuild the renderer)`。

檔頭註解改寫（不再提 aux）。檔內與整個 `Module/` 不得再出現 `IRenderAux`、`Draw2dImage`、`Draw2dLabel`、`IRenderAuxGeom.h`。

- `UpdateAfterRender`：由全螢幕播放器組 `SLayer`（打包排列時填平面矩形與色彩欄位，取值方式與契約快照相同——重用 `VideoPlayerImpl.cpp:1335-1354` 那段的來源，抽成一個播放器成員函式供兩處使用）；**不再跳過非 RGBA8 的播放器**；呼叫 `FullscreenOutput::Present`。除錯圖層由 `Console.cpp` 提供（見 §3）。

- `Shutdown` 時呼叫 `FullscreenOutput::Shutdown()`（在貼圖釋放之前）。
- `CVideoPlayerImpl::DesiredLayout`（約 :1525）改為：
  - 有材質綁定、`cev_allowPlanar 0`、來源不可打包 → RGBA8（不變）。
  - 沒有 Surface 也不是全螢幕 → RGBA8（不變）。
  - 全螢幕：`FullscreenOutput::SupportsPlanar()` 為假 → RGBA8。
  - 有 Surface：照現行的 hint 規則判斷它是否接受打包（沒有消費端、或消費端不接受 → 不接受）。**同時是全螢幕又註冊了 Surface 且有消費端時，兩者都接受才用打包**；Surface 沒有任何消費端時只看全螢幕。
  - `consumerDriven` 的意義照舊（由 hint 決定時為真）；全螢幕單獨決定時為假。先讀 `UpdateLayout` 確認 `consumerDriven` 為假時切換排列的行為正確（會不會卡在等待 hint），有疑問停下回報。
